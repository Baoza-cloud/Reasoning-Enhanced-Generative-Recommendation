# HTTP 端到端并发压测

> 延迟覆盖 HTTP 收发、JSON 解析、模型推理、Trie Beam、结果组装与 JSON 序列化。

## 固定协议

- 平台：`macOS-10.16-x86_64-i386-64bit`；
- CPU：`8` 逻辑核；
- Beam：`20`；
- 每个组合持续：`10.0` 秒；
- 长尾模式：`off`；
- 样本：Amazon Reviews 2023 / Musical Instruments 真实 Test 历史；
- 服务进程：单 worker，模型推理串行保护。

## 说明

并发升高时，单 worker 的模型锁会把请求排队，因此尾延迟会增加。Batch 推理以一次请求处理多条历史，提高用户历史吞吐，但单请求响应体也更大。所有成功响应均校验返回条数；超时、非 200 和响应契约错误单独计数。
